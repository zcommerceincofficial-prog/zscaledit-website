# keep-list.txt
#
# Files and folders that must survive every re-export.
# scripts/export-transform.mjs copies each line into dist/ untouched, every run.
#
# One path per line, relative to the project root (the folder holding site/ and dist/).
# A line starting with # is a comment. Blank lines are ignored.
# End-of-line comments do NOT work: "assets/logo.png  # the logo" is read as a
# filename with spaces in it and the build fails saying it cannot find it.
# A path that ends in / is copied as a whole folder, recursively.
#
# The build EXITS 1 if a path listed here does not exist. That is on purpose:
# a keep-list file that quietly disappeared is how a hero animation stops shipping.
#
# Anything you or Claude built that the design tool did not know about goes here.
# Uncomment the lines you actually use and add your own.
